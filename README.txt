PERSONAL PORTFOLIO
==================

1. Open index.html in a browser.
2. Replace "Your Name", "YN", email, social links, and other placeholder details.
3. Replace the project descriptions with your actual projects.
4. To add a profile photo, replace the .profile-placeholder element in index.html with an <img>.

Files:
- index.html  -> page structure/content
- style.css   -> responsive design/animations
- script.js   -> typing animation, scroll reveal, mobile menu, progress bar
